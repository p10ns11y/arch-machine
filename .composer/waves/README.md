# Sentinel Waves

This folder is the execution map for autonomous sentinel agents.

## Sentinel Roles

- `Virtinel`: trustworthy default guardian for stable daily-driver improvements.
- `Trusinel`: long-term reliability, validation, and regression hardening.
- `Eusinel`: experimental and evolving enhancements.
- `Safinel`: maximum hardening and high-security behavior.
- `Guardwell`: clarity, onboarding, and operator-facing simplicity.

## Active Priority Waves

1. `wave-1-core-stabilization.md` - `P0` core stabilization and installer correctness.
2. `wave-2-security-remediation.md` - `P1` security hardening and remediation execution.
3. `wave-3-ops-reliability-automation.md` - `P2` operational reliability and automation hardening.
4. `wave-4-ai-evidence-extraction.md` - `P3` AI evidence extraction stream, with `P3(10)` kept as separate session.
5. `wave-5-optional-offline-and-docs.md` - `P4` offline-first consented network flow + docs.

Source priority ordering is maintained from `generated-priority-list-from-plans.md`.

## Regression Tracking

Use `regression-error-log.md` as the canonical fillable defect table and bucket map.

## Coordination Files
