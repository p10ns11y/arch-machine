# Orwell tweak law — skill overlays

Apply when writing or refreshing project overlays. Goal: **almost no wasted tokens**, still actionable.

## Six rules (Orwell → agent skills)

| Orwell | Overlay rule |
|--------|----------------|
| Never use a metaphor you are used to seeing in print | Drop empty “journey / ecosystem” fluff |
| Never use a long word where a short one will do | Prefer *run*, *wire*, *cut*, *refuse* |
| If it is possible to cut a word out, cut it out | One idea per line |
| Never use the passive where you can use the active | “Agent runs `make lint`” |
| Never use jargon if everyday English will do | Keep contract terms (`install_*`, Msg, Cmd) |
| Break any of these sooner than say anything outright barbarous | Clarity > purity |

## Action orientation

Every block: **do what, where, when fail**.

## Diagram budget

One fused loop per overlay. No second prose restating it.

## Compression budget

| Keep | Drop |
|------|------|
| Live entrypoints + verify commands | Dead legacy as primary |
| Never-compress list | Motivational essays |
| Refuse vs build | Hedge walls |

Target: overlay **≤ ~50 lines**.

## Verify after tweak

1. Paths exist.
2. Primary surface matches AGENTS.md.
3. Overlay only — no edits to locked skill bodies.
