# Wallpaper layout (impeccable *layout*)

Safe composition for floating terminals on Omarchy/Hyprland:

| Zone | Approx | Keep |
|------|--------|------|
| Upper 35–40% | Quiet | Soft sky / empty field — terminals float here |
| Mid band | Soft | Low-frequency texture only |
| Lower third | Calm anchor | Subject / gradient rest; not high-frequency detail |

Do / don't:
- Prefer soft gradients and negative space over busy collage
- Grade luminance toward SoT bg (cream day / umber night)
- Avoid faces, text, or high-chroma hotspots behind code windows
- 16:9 primary; fill via swaybg

Phase hints (filename under `backgrounds/`): see `PHASE_WALLPAPER_HINT` in `lib/palette.py`.
Dawn/light packages share light backgrounds; dusk/dark share dark backgrounds (install symlinks).
