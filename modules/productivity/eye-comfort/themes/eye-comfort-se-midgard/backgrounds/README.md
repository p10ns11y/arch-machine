# Wallpaper set — Tinai × Siru (Karu Porul stage)

Eye comfort first: calm lower third, soft gradients, quiet upper 30–40% for
floating terminals. No busy narrative scenes behind text-heavy windows.

## Filename convention

Hints: `{tinai}-{siru}-{a|b}.jpg` · `a` = Nazhigai 0–4 · `b` = 5–9

## Ships with (kurinji)

| File | Notes |
|------|-------|
| `kurinji-yaamam-{a,b}.jpg` | Signature night mountain mist (tinai meta siru) |
| other `{siru}-{a,b}.jpg` | Softlinks → yaamam signature |
| `kurinji-default.jpg` | Softlink → yaamam-a |

Switcher fallback: exact → `-b`→`-a` → tinai signature → `*-default.jpg`.

Install rsyncs to `~/.config/omarchy/themes/<package>/backgrounds/`.
Cycle: `omarchy theme bg next` · Apply: `eye-comfort-theme tn …`
