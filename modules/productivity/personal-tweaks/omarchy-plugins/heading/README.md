# Heading (Omarchy bar widget)

**BarWidget + Panel** views (weather-style split). Chip: **icon + semantic** (e.g. `󰠔 Cash`). Panel: `ButtonGroup` slots (`focus-now set 1–4`), short apply blurb, **Open** (kanithanj.ai) / Notify.

```bash
rsync -a --delete ./ ~/.config/omarchy/plugins/heading/
omarchy plugin validate ~/.config/omarchy/plugins/heading
omarchy restart shell   # never refresh
```

Clicks: left toggle · right mission notify · middle refresh.
