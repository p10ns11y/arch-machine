# Plan: Port Security Audit Scripts into Modular Structure

## Current State Analysis
- **Existing Structure**: Modular system with profiles, tools config, modules, and maintenance scripts
- **Security Dev Profile**: Includes `security.full` which installs k3s, Cilium, Tetragon, encrypted storage
- **Existing Tools**: lynis, clamav, rkhunter, chkrootkit in maintenance/security-audit.sh
- **New Tools**: osv-scanner, grype, syft (from vulnerability-tools-installer.sh)
- **New Audit Features**: Multi-language vuln scanning (Node/Python/Rust), SBOM generation, OSV-Scanner universal scanning
