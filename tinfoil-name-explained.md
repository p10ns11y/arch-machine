# Why the shim is called “tinfoil”

> **Not a quick-start.** Day-1 interactive control is **`archy`** — [docs/archy.md](docs/archy.md) · [docs/INSTALLATION.md](docs/INSTALLATION.md).  
> This page is name humor only.

**tinfoil** is the humorous name for the optional Go **CLI shim** that thin install still places on PATH until SN-ARCHY-1 ships `archy`.

### Classic “tinfoil hat” vigilance joke

- “Tinfoil hat” is an idiom for taking protection and awareness to the extreme.
- Naming the shim **tinfoil** is self-aware: the project embraces exaggerated vigilance with a grin.
- The platform audits itself, remediates by policy, and keeps evidence — “ridiculously vigilant… and proud of it.”

### Short and silly to type

- One word: `tinfoil`
- Saying **`tinfoil .`** out loud is absurd on purpose — memorable because it’s silly.

### Fits the voice

README humor (“audits itself harder than your ex…”) matches the name. The **product loop** is still archy + shell backends + evidence — not this essay.
